## 2. Adaptation Walkthrough Example: "AI Observability Platform"

If a user says: *"Build a landing page for my new AI agent monitoring platform 'TraceAI' using this style"*:

### 1. Brand Tokens
- Brand hue: `255` (Indigo/Purple `#6366F1`)
- Secondary: Green `#22C55E` (healthy agents), Amber `#F59E0B` (rate limits), Red `#EF4444` (hallucinations/errors).

### 2. Headline & Plume
- Title: `<span class="hl">Stop</span> Debugging in the Dark. We trace <span class="hl">every token</span>.`
- Orbiting chips: `Trace Explorer`, `Cost Sentinel`, `Eval Engine`, `Prompt Playground`.

### 3. Hardware Cockpit
- Left column: Active Agents list (`ResearchAgent`, `CoderBot`, `SupportAgent`) with latency and status badges.
- Center column: Token volume, cost per million tokens, latency range slider (Min 180ms, Max 620ms).
- Right column: Hallucination score gauge (98.2% Accurate) and live execution error log.

### 4. Integration Pipeline
- Left nodes: LangChain, LlamaIndex, AutoGen
- Center Hub: TraceAI Glowing Core
- Right outputs: Real-time Tracing, Anomaly Alerts, Cost Analytics, Evals.

### 5. Sonar Scanner
- Headline: "The rest of your stack, monitored continuously"
- Radar satellites: "Vector Databases", "Prompt Injections", "Rate Limits", "Latency Spikes".
