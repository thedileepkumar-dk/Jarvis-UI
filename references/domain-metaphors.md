# Domain Metaphor Mapping: Designing Animations for Any Product

A major mistake in web engineering is copying a single visual metaphor (like a stock market watchlist or a sonar radar) into unrelated projects. 

Instead, **analyze the product's core physics and value proposition**, then choose metaphors that tell that specific product's story.

---

## 1. The Metaphor Synthesis Formula

Ask these 3 questions for any user request:

1. **What is the primary "matter" moving through this product?**
   - Data / Packets / Tokens / Money / Audio / Users / Shipments / Code.
2. **What is the product's primary action?**
   - Routing / Filtering / Guarding / Accelerating / Synthesizing / Visualizing.
3. **What does "success" look like as a physical meter?**
   - Low latency / High uptime / Profit yield / Accuracy score / Conversion velocity.

---

## 2. Industry Mapping Table

### A. AI & LLM Developer Platforms
- **Primary Metaphor**: Synaptic routing, token streams, evaluation firewalls.
- **Hero Centerpiece**: Live prompt sandbox or multi-model latency comparison cockpit.
- **Kinetic Animations**:
  - Traveling pulse paths representing prompts routing across Claude, GPT-4, and Gemini.
  - Live token streaming ticker (`tabular-nums` counting tokens/sec).
  - Hallucination / accuracy gauge with needle.

### B. Cloud Infrastructure & DevOps
- **Primary Metaphor**: Global network topology, packet routing, CI/CD release pipeline.
- **Hero Centerpiece**: Live server cluster monitor with node status badges.
- **Kinetic Animations**:
  - Git commit flow moving along an SVG branch from `main` -> `build` -> `multi-region edge`.
  - Server rack LED status pulses (green/amber/red).
  - Real-time CPU/Memory radial dials.

### C. Cyber Security & Zero-Trust
- **Primary Metaphor**: Shield firewalls, perimeter scanning, threat neutralization.
- **Hero Centerpiece**: Real-time security operations center (SOC) event map.
- **Kinetic Animations**:
  - Scanning horizontal laser beam across an encrypted payload.
  - Hexagonal protective mesh pulsing on attack blocked.
  - CVE severity gauge.

### D. E-Commerce & DTC Brands
- **Primary Metaphor**: Flash drops, product unboxing, global fulfillment velocity.
- **Hero Centerpiece**: 3D perspective-tilted product card with reactive sheen.
- **Kinetic Animations**:
  - Live counter: "1,248 orders placed in the last hour".
  - Interactive colorway switcher with smooth ripple transitions.
  - Dynamic checkout drawer with spring physics.

### E. FinTech, Crypto & Trading
- **Primary Metaphor**: Real-time liquidity, order matching, risk regime.
- **Hero Centerpiece**: Desktop multi-column cockpit (Watchlist, Indices, News).
- **Kinetic Animations**:
  - Up/Down price flash animations (`@keyframes greenFlash`).
  - Fear & Greed sentiment gauge arc.
  - Low/High day range progress bars with sliding thumb markers.

### F. Audio, Podcasting & Media
- **Primary Metaphor**: Sound waves, vinyl grooves, resonance.
- **Hero Centerpiece**: Interactive audio waveform canvas.
- **Kinetic Animations**:
  - Animated equalizer bars (`scaleY` bouncing to rhythm).
  - Orbiting turntable / audio visualizer ring.
  - Dynamic scrubbing waveform player.

### G. Healthcare & Biotech
- **Primary Metaphor**: Vitals telemetry, molecular synthesis, diagnostic triage.
- **Hero Centerpiece**: Patient telemetry dashboard or molecular sandbox.
- **Kinetic Animations**:
  - ECG heartbeat waveform path drawing.
  - Triage health status gauge (Optimal, Warning, Critical).
  - Encrypted EHR pipeline synchronization lines.
